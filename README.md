# EwNet Sistemas — Website

> Landing page institucional da EwNet Sistemas, especializada em sistemas de gestão para lojas e restaurantes.

## 📋 Sobre o Projeto

Website institucional desenvolvido para apresentar as soluções de gestão da EwNet, empresa com mais de 15 anos de experiência no mercado e mais de 1.000 clientes satisfeitos.

### Segmentos Atendidos

- Varejo / Lojas
- Restaurantes
- Food Service
- Delivery

## 🛠️ Tecnologias

- **HTML5** — Estrutura semântica
- **CSS3** — Estilização com variáveis CSS, design responsivo
- **JavaScript** — Interatividade (menu mobile, animações)

### Fonts

- **Sora** — Tipografia para títulos
- **DM Sans** — Tipografia para corpo de texto

## 📁 Estrura

```
website/
```
